# Header-component

Это React-компонент, созданный с использованием Vite, TypeScript и поддержкой горячей перезагрузки (HMR). Проект идеально подходит для быстрого старта разработки, тестирования и интеграции промо-компонентов в более крупные приложения.

## Стек технологий

* **React** – построение интерфейсов
* **TypeScript** – статическая типизация
* **Vite** – быстрый сборщик и dev-сервер
* **ESLint** – анализ кода и контроль стиля

## Структура проекта

```
Promo-component/
├── public/                # Публичные файлы
├── src/
│   ├── assets/            # Статические ресурсы (изображения, иконки)
│   ├── component/         # React-компоненты
│   ├── App.tsx            # Главный компонент приложения
│   ├── main.tsx           # Точка входа
│   └── index.css          # Глобальные стили
├── index.html             # HTML-шаблон
├── package.json           # Зависимости и команды
├── tsconfig*.json         # Конфигурации TypeScript
├── vite.config.ts         # Конфигурация Vite
└── README.md              # Документация
```

## Быстрый старт

1. **Установите зависимости:**

   ```bash
   npm install
   ```

2. **Запустите локальный сервер:**

   ```bash
   npm run dev
   ```

3. **Откройте в браузере:**

   ```
   http://localhost:5173
   ```

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`.

## Линтинг кода

Для проверки кода на ошибки и соответствие стилю используйте:

```bash
npm run lint
```

## Добавление компонентов

Добавляйте свои компоненты в папку `src/component/`. Для стилей используйте отдельные CSS-файлы в той же папке.

## Настройка ESLint

Проект уже содержит базовую конфигурацию ESLint для TypeScript и React. Чтобы изменить или расширить правила, смотрите примеры в `eslint.config.js`.
